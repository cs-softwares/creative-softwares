# Creative Softwares

A professional website for Creative Softwares, a startup consultancy specializing in utility apps and websites.

## About

Creative Softwares is dedicated to creating innovative utility applications and websites. Our portfolio includes a scientific calculator app published on Google Play Store, custom apps for clients, and an upcoming DSA learning app.

## Features

- **Home**: Hero section with company overview
- **About**: Company story, mission, vision, and team
- **Services**: Comprehensive list of development services
- **Portfolio**: Showcase of our projects and apps
- **Contact**: Contact form and information

## Tech Stack

- **Framework**: Next.js 16 with App Router
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Deployment**: Ready for Vercel or any static hosting

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for Production

```bash
npm run build
npm start
```

## Deployment

This project can be deployed on Vercel, Netlify, or any platform supporting Next.js.

For Vercel deployment:
1. Push to GitHub
2. Connect to Vercel
3. Deploy automatically
